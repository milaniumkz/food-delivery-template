# Food Delivery · White-label starter

Основа коммерчески развиваемого приложения доставки еды для отдельных ресторанных брендов. **Это подготовленный репозиторий и дизайн-прототип, а не готовая система доставки.**

## Состав и реальное состояние
| Часть | Подготовлено | До production |
|---|---|---|
| Техническое задание | Подробные требования, API, модель данных, этапы, критерии приёмки | Согласовать бизнес-параметры клиента |
| Дизайн | Токены, UX, интерактивный HTML-макет каталога, корзины, оформления и панели | Пользовательские тесты и реализация всех экранов |
| Mobile | Flutter starter с темой из конфигурации бренда | Native runners, API, авторизация, каталог, заказы, push |
| Server | Исполняемый контракт платежей, mock-провайдер, тесты | NestJS, PostgreSQL, полноценные модули и защищённые API |
| Admin | Спецификация панели и интерактивный макет | Next.js, RBAC, API, реальные операции |
| Kaspi | Fail-closed адаптер без реальных платежей | Найти исходник, проверить права, договор и API |
| White-label | Проверка и генерация безопасной публичной конфигурации | Native icons, signing, store metadata, автоматизация сборок |

## Быстрый просмотр
```sh
python3 -m http.server 8080 --directory design
# http://localhost:8080 — только локальный демонстрационный макет
node tools/brand.mjs brands/demo/brand.json
node --test apps/api/test/*.test.mjs
```
Интерактивный макет работает с демонстрационными данными в памяти; не передаёт платежи или заказы.

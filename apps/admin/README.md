# Admin foundation

Next.js shell читает публичный бренд через @food/config и показывает фактическую доступность API readiness. Подтверждены сборка и HTTP smoke с двумя брендами. Доступа сотрудников, управления меню/заказами и кабинета курьера ещё нет; привилегированные API не открыты.

Из корня: pnpm dev:admin. Настройка и проверки: ../../docs/local-development.md. Статический design/index.html остаётся отдельным прототипом.

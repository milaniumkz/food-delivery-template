Сохранённый draft разрешает storage.googleapis.com, api.github.com, binaries.prisma.sh и OSM domains; **действующая политика ещё без этих custom domains**. Сохранение draft не применяет её и не публикует среду. TLS/checksum не отключались. APK/Web не помечаются passed по наличию runners.

Prisma7.10.1 generate/migrate работают через закреплённые JS/WASM helpers; внутренние tooling API требуют полного migration/integration прогона при upgrade. Реальные SMS/FCM/S3/Kaspi, production TLS/hosting, юридические тексты, signing и физические устройства не предоставлены. Независимые недореализованные SPEC функции перечислены в acceptance.md, а не замаскированы под access blockers.

Git read через origin подтверждён. GitHub API `gh pr list` вернул Forbidden; это не отсутствие Git authentication и не основание требовать PAT. Удалённый PR/Actions не считать созданными/пройденными до отдельного подтверждения. Текущий результат подготовлен для review; публикация магазинов, deployment и реальные финансовые операции не выполнялись.

## Этап совместимости и проверки ролей

Добавлены server-validated пары несовместимых variants/choices (включая запрет обратных дублей, неизвестных/group/self IDs), guided editor админки и блокировка несовместимого выбора Flutter. Создание заказа повторно проверяет новые правила; после изменения конфигурации старый quote не создаёт заказ/платёж. Повтор заказа пропускает архивные/несовместимые опции с явным перечнем, не подменяет состав и берёт текущие цены. API35/35,25unit/tool+6HTTP и Flutter analyze+17/17 прошли. Полный browser/headless Flutter E2E4/4, включая editor/axe, прошёл.

Исправлена найденная при review privacy ошибка совмещённых ролей: manager/operator/dispatcher другого филиала больше не раскрывает contact/address/финансы кухне текущего. Regression проверяет список, детали, prepare response и запрет manager-only cancel; owner сохраняет глобальную роль. Новых миграций не потребовалось (конфигурация JSON обратно совместима).

Дополнительно проверены: erasure удаляет собственные transient IdempotencyRecord snapshots с адресом/комментарием, сохраняя чужие записи; offline logout очищает local credentials/профиль, сохраняет unresolved checkout и явно сообщает, что remote revocation не подтверждён. История не запрашивается гостем, автоматически загружается после login и обновляется pull-to-refresh даже при пустом списке. Flutter17/17.

Docker regression: исправлено создание private SMS directory (uid1000/mode0700) до mount fresh volume; явный SMS_DIRECTORY внутри Compose. `pnpm test:containers` проверил отдельный disposable database/контейнер/fresh volumes: non-root, отсутствие embedded credentials, реальный OTP/session, staff MFA, Sharp WebP upload/read, server quote, mock payment/full refund. Временные ресурсы удалены. Старый локальный SMS volume исправлен только по metadata; существующие коды не печатались.

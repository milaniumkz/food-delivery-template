# Дизайн · TAMAK / настраиваемый бренд

Направление: тёплая светлая поверхность, выразительная типографика, терракотовый акцент и тёмно-зелёный текст. Воздух, крупные кнопки, ясная стоимость доставки и короткий путь к заказу. Без фотографий неизвестного происхождения: текущие карточки используют emoji на собственных CSS-фонах. Реальные food-фотографии — единый квадратный crop, права клиента и оптимизированные WebP/AVIF.

## Компоновка клиента
Mobile 360–430: шапка с брендом и адресом; заметное время/стоимость; hero оффер; горизонтальные категории; карточки в 1–2 колонки с адаптацией; закреплённая корзина над safe area; нижняя навигация Каталог/Заказы/Профиль при будущей реализации. Desktop 1280+: max-width 1240, каталог слева, корзина 340px справа. Прототип использует боковую корзину на desktop и раскрываемую корзину на mobile.
Карточка: иллюстрация, название, описание, вес, цена и кнопка добавить. Никаких скрытых доплат. Корзина: выбранные позиции, +/- controls, доставка и итог. Checkout: отдельная короткая форма, способ получения, адрес, комментарий, оплата; итог и явное действие. Mock подтверждение помечено «Демонстрация».

## Карта экранов клиента
Старт/адрес → каталог → поиск/категория → блюдо/модификаторы → корзина → вход OTP → оформление → оплата → подтверждение → детали и статусы. Из профиля: история/повтор, адреса, язык, поддержка, согласия/удаление. Для каждого нужны skeleton, empty, error+retry, offline. Ошибки форм inline с сохранением ввода; не полагаться только на toast.

## Панель
Тёмная навигация слева desktop, компактная верхняя navigation mobile. Разделы: Обзор, Заказы, Меню, Филиалы, Промокоды, Клиенты, Настройки. Рабочая область: KPI с определением периода, поиск/фильтры, таблица с номером, временем, типом, статусом и суммой. Статус badge с текстом. Правая карточка заказа — детали, история и одно основное разрешённое действие; destructive отмена/возврат через подтверждение причины. Текущий HTML показывает только демонстрационную таблицу и KPI.

## Компоненты и состояния
Button primary/secondary/destructive: idle, pressed, loading, disabled; min-height 48. Input: label, hint, error, focused, disabled. ProductCard, CategoryChip, QuantityStepper, Money, StatusBadge, AddressSelector, OrderTimeline, EmptyState, Alert, Modal, Toast. Modal: закрытие Esc, focus trap и восстановление focus; текущий макет использует native dialog. Значение количества проговаривается screen reader. Иконка без подписи имеет aria-label; активный элемент виден клавиатурой.

## Что уже можно посмотреть
`design/index.html`: responsive каталог, фильтры категорий/поиск, добавление/удаление и подсчёт корзины, demo checkout с проверкой адреса, сообщение demo-заказа, admin view и настройки бренда в памяти. Данные не сохраняются на сервер, оплата не выполняется. Форма бренда изменяет CSS variables, логотип и имя через единую конфигурацию. Flutter реализует каталог/поиск/категории, опции, корзину, OTP, серверный расчёт, mock оплату, статусы, историю, повтор и профиль. Реальное состояние и непроверенные дизайн-критерии — в progress/acceptance; HTML остаётся отдельным демонстрационным макетом.

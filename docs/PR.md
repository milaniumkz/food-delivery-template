# Рабочий контур доставки: Flutter, API, ресторан и курьер с mock оплатой

Исходный starter не имел HTTP сервера, БД и рабочей панели. Теперь гость собирает корзину во Flutter, входит по local OTP, подтверждает серверный расчёт и mock оплату; ресторан готовит заказ, курьер завершает доставку либо оператор выдаёт самовывоз по коду. Деньги/роли/переходы проверяются сервером, транзакции защищают остатки, промокоды, идемпотентность и финансовые эффекты.

Добавлены NestJS/PostgreSQL/Redis, Next.js BFF с brand guard и cookie/CSRF/MFA/RBAC, каталог/варианты/media, расписания/зоны/promos, operations/refunds/outbox, профиль/удаление, защищённый paginated privacy export, публичный web deletion, branch-scoped customer restrictions, reports/diagnostics, два бренда и генерация native identity/assets. Подготовлены Docker Compose приложений, pinned SDK/locks, OpenAPI и TS/Dart clients, CI, load и restore/PITR drills.

Проверено локально: lint/format/types;24 unit/tool+6 HTTP;34 PostgreSQL integration;Flutter analyze+13 tests;4 E2E (browser admin/customer restriction/axe, BFF brand guard и публичное удаление с двумя OTP, Flutter pickup, Flutter delivery через mobile courier browser); API/admin build, два brand HTTP smoke, dependency audit0; logical/media restore, Redis outage и physical WAL/PITR. 30min load baseline:36000reads/600orders/600attempts,0errors; последние изменения проверены коротким load smoke. Подробности и границы: progress/acceptance/VALIDATION.

14 миграций применяются helpers на pinned Prisma JS/WASM. На существующих данных не выполнялись reset/truncate. Откат — восстановление согласованного backup либо forward migration после review; enum/constraint migrations не предполагают слепой destructive down. Root seed сохраняет данные и оставляет филиал закрытым до бизнес-настроек владельца. Отдельные temporary DBs runner удаляет сам.

Не готово к production: APK/Web artifacts заблокированы storage.googleapis.com403; iOS archive/devices/signing не проверены; нет утверждённых Kaspi/SMS/push/hosting/legal/offsite конфигураций. В acceptance.md отдельно перечислен оставшийся программный объём SPEC. NODE_ENV=production и реальный Kaspi fail-closed. Никаких реальных платежей, deployment или store publication. Секреты только ignored local files; limited secret scan выполнен. Remote CI/PR должны быть подтверждены отдельно.
